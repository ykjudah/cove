# Cove 1.2

- Keel is the playable map for new feedback matches. Character-scale play with a follow camera, continuous walking and wall collision.
- Illustrated ship, volcanic and polar interiors. Hand-drawn animated suits, visors, walking animations, bodies and ghosts.
- Walls limit sight. Power sabotage reduces innocent vision until repaired.
- Role introduction and optional map overview. The server checks movement and interaction distances and limits which player positions are visible.
- Includes the existing Open Games, friends invitations, host settings, meetings, tasks and private roles.
