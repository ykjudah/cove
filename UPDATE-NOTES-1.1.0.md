# Cove 1.1

- Open Games sidebar tab with friend invites, private lobbies and resumable Imposter matches.
- Three original room-based maps: Keel, Caldera and Frostline. Only Imposter and Innocent roles.
- Host settings for imposter count, tasks, kill cooldown and voting time. Includes task progress, power sabotage and repair, body reports, meeting chat, anonymous ballots, ghosts and team victories.
- Optional native Windows message/call notifications. Click a popup to open its chat. Optional close-to-tray with a Quit Cove menu item.
- Removed head-to-head profile stats.
