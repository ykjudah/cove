# Cove 1.6.15

- Cove name and monochrome wave logo throughout the app and desktop icon.
- New users start with Ocean at 0% color intensity; saved themes are preserved.
- Password visibility eye buttons for sign-in and account settings.
- Winning game cards disappear for spectators; the players see You won / You lost. Win totals are retained.
- Starting a new call disconnects your previous calls. Other people can continue their group calls.
- Built-in update source: https://github.com/ykjudah/cove (including https://). No URL setup required.
- Verified downloaded updates clear unsent drafts and automatically install/restart.

Includes all 1.6.14 account, emoji, theme, and read-receipt improvements. Database migration required.
