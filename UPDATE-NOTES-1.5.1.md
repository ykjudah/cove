# TungChat 1.5.1

- Ball stripes and numbers roll with their movement, with fixed lighting.
- Reshaped cream pocket surrounds and angled corner pocket openings.
- One solids/stripes ball badge replaces each remaining-ball list.
- Thicker aiming guides and a cue-ball deflection guide.
- Pull the back of the cue stick to set power; release to shoot. The meter still works.
- Emoji picker beside the Games button, with search and insertion at the cursor.

Includes all 1.5.0 changes. No new SQL is needed if the 1.5.0 games migration was already run.
