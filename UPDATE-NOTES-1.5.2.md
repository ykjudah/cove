# TungChat 1.5.2

- Games button only sends new game invitations; open existing games from their chat cards.
- Added an 8-ball thumbnail to the send menu and invitation cards.
- Returning shot power to zero cancels the shot when released.
- Accept & play: the accepting player immediately takes the opening shot.
- Sending an invitation returns directly to chat.

Includes the rolling balls, pocket styling, group badges, cue dragging, trajectory guides and emoji picker from 1.5.1.
